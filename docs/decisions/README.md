# Decisões (ADRs)

Um arquivo por decisão de arquitetura, numerado em ordem: `NNNN-titulo-curto.md`.
Cada ADR diz o contexto, a decisão, as alternativas descartadas e as consequências.
ADR não se edita depois de aceito: se a decisão mudar, escreva outro que o substitua.
